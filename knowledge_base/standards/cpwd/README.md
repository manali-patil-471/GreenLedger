# CPWD material reference factors

Source publication: *Reducing Carbon Footprint in Buildings*, Central Public Works Department (CPWD), Government of India, 2024.

- Official source URL: https://cpwd.gov.in/Publication/Reducing_Carbon_Footprint_in_Buildings_2024.pdf
- Local source artifact: `Reducing_Carbon_Footprint_in_Buildings_2024.pdf`

- Retrieved as an archived copy of the official CPWD URL captured 2025-07-11 (`20250711213918`) because the CPWD origin rejects direct automated retrieval. The PDF itself identifies the CPWD publication and the factor table.
- Factor table: Chapter 1, “Carbon Factor data used for calculating the Embodied CO2”, printed page 11.

GreenLedger v1 uses only the three project-selected rows as generic/reference factors: Portland Pozzolana Cement (PPC), 0.760 kgCO2e/kg; Steel Rebars, 3.450 kgCO2e/kg; and Steel, 2.100 kgCO2e/kg. The source table specifies 30% fly-ash content for PPC, says the rebar value is from a Jindal Steel EPD, and says generic steel is a weighted average of BOF, DRI, and EAF production. Those source notes are retained in the catalogue. GreenLedger does not perform supplier-specific EPD matching or substitute supplier values.

These are narrow generic/reference material factors. The source table is a building-material reference table; its use for purchased goods is restricted to the explicit material identities and Scope 3 Category 1 gate in GreenLedger. No other CPWD rows are enabled.
